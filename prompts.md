# Uso de IA

**Ferramenta:** Claude Code (Anthropic).

A ideia da CitizenTech (Escola no Prazo), o MVP (participação em uma apresentação de boas práticas) e o que esta disciplina deveria fazer (grafo de dependências e caminho crítico) foram definidos pela equipe. A IA foi usada para ajudar a implementar o código, os testes e o README a partir desses materiais.

## Resumo dos prompts

1.Falamos sobre os PDFs da GS, os comentários do professor de Dynamic Programming, a apostila da disciplina e a ideia do projeto, e tivemos ajuda para implementar em Python o grafo de dependências e do cálculo do caminho crítico, seguindo apenas o que o professor pediu.
2. Enviamos os nomes e RMs da equipe, e pedimos para completar a Ficha da CitizenTech e preparar o ZIP de entrega.
3. Pedimos para subir o código no repositório do GitHub da equipe e explicar como rodar o programa no Spyder.
4. Decidimos simplificar o código, mantendo todos os requisitos do professor e garantindo que tudo funcionasse (ficaram grafos + tabulação, com testes).
